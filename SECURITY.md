# Reporting a vulnerability

Please do not open a public issue for a security problem. Use **Report a vulnerability** on the
repository's **Security** tab to send a private report, or contact the maintainer directly.

Include the plugin version, the GLPI version, the steps to reproduce and the impact you expect. Do
not include real credentials, host names or personal data; describe them instead.

You will get an answer within 7 days. Fixes are released as a new release candidate first, then as a
final version, as described in `CHARTER.md`.
