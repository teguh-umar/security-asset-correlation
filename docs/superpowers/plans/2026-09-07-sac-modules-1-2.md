# SAC Modules 1 & 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `sac` GLPI 11 plugin scaffold plus Module 1 (EOL/EOS correlation) and Module 2 (License Governance), emitting `Finding` records into the `riskregister` plugin.

**Architecture:** A GLPI 11 plugin (PSR-4 `GlpiPlugin\Sac\`). Three weekly cron tasks scan GLPI-native data (+ one free API) and correlate signals to `Computer` assets. Findings are written **in-process** through `riskregister`'s `Finding` itemtype API via a single `FindingWriter` class — SAC never touches `riskregister`'s tables. SAC keeps 5 of its own `glpi_plugin_sac_*` tables for signal mapping, an API cache, a reconcile queue, and run audit. Pure logic (severity ladders, code builders, version-cycle parsing) lives in dependency-free classes tested offline with `C:\php\php.exe`; everything GLPI-coupled is verified by `selfChecks()` on the VM.

**Tech Stack:** PHP 8.2+ (8.4 on both dev CLI and VM), GLPI 11 plugin API, `riskregister` plugin (v1.1.0+), `fields` plugin v1.23.2 (read-only), `endoflife.date` public API. No Composer runtime deps. No PHPUnit — `selfChecks(): array<string,callable>` pattern (matches `riskregister`).

**Spec:** `docs/superpowers/specs/2026-09-07-sac-modules-1-2-design.md` — read it alongside this plan.

## Global Constraints

- **Namespace / prefix:** PSR-4 `GlpiPlugin\Sac\` → `src/`; every table `glpi_plugin_sac_*`; config context exactly `plugin:sac`; rights `plugin_sac_finding` and `plugin_sac_config`; cron class `GlpiPlugin\Sac\Cron`; menu sector key `sac`.
- **Plugin metadata:** `setup.php` `plugin_version_sac()` → `'name' => 'Security-Asset Correlation'`, `'author' => 'ICT'` (exact), `'license' => 'GPL-3.0-or-later'` (exact). `composer.json` `"license": "GPL-3.0-or-later"`. GLPI requirement `min 11.0.0`, `max 11.9.99`.
- **GLPI 11 signature rules:** `canView(): bool` and the full `can*` set typed `: bool` on `CommonGLPI`/`CommonDBTM`/`CommonDBRelation` subclasses. `\Profile` tab hooks: `getTabNameForItem()` non-static instance, `displayTabContentForItem()` static. Never `Session::checkCSRF()` in a front file. Never `Html::clean()`. Never a closure for a dashboard-card `provider`/`function` (string `"Class::method"` only). Form `action` never `$_SERVER['PHP_SELF']` — use `Html::getPrefixedUrl('/plugins/sac/front/<x>.php')` or `<Itemtype>::getFormURL()`. `Html::header()` 2nd arg is ignored — pass `''`.
- **Timestamps:** every `date_creation`/`date_mod` column is `timestamp NULL DEFAULT NULL`. After install on the VM, `bin/console migration:timestamps` must report clean.
- **No local GLPI runtime:** `C:\php\php.exe` = PHP 8.4, extensions: `json` only (no `mbstring`, no `curl`, no `openssl`, no `php.ini`). Offline tests must not use `mb_*`, network, or GLPI classes. Every source file must pass `"/c/php/php.exe" -l`.
- **riskregister contract (pinned, hub §5):** create Findings only via `\GlpiPlugin\Riskregister\Finding` `->find()/->add()/->update()`, guarded by `\Plugin::isPluginActive('riskregister')`. `code` deterministic ≤50, unique `(entities_id, code)`. `scope_label` always non-empty. `severity ∈ {Critical,High,Medium,Low,Info}`. `status` set on create only. Category via `\GlpiPlugin\Riskregister\Import\ImportSupport::categoryIdByName($name,$eid)` which **returns 0 on miss (no auto-create)** — tolerate 0. Never set `id`/`is_deleted`/`date_creation`/`date_mod`. `datainjection` path unused.
- **Commit cadence:** one commit per completed step group as marked. Commit messages end with the Co-Authored-By trailer already configured for this repo.
- **Suite coordination:** after Task 12, append a dated entry to `…/Documents/_pgn-glpi-suite.md` §7 and bump its header (hub §0).

```php
<?php
// Runs the dependency-free selfChecks() with C:\php\php.exe — no GLPI, no network.
// Usage: "/c/php/php.exe" tools/offline-selfcheck.php [filter]

function sac_assert(bool $cond, string $msg): void
{
    if (!$cond) { throw new \RuntimeException($msg); }
}
function sac_assert_eq(mixed $got, mixed $want, string $msg = ''): void
{
    if ($got !== $want) {
        throw new \RuntimeException(($msg ?: 'not equal')
            . ' — expected ' . var_export($want, true) . ', got ' . var_export($got, true));
    }
}

$root  = dirname(__DIR__);
$pure  = ['Severity', 'Code', 'EolMatch', 'FindingWriter']; // classes with a pure selfChecks() subset
$filter = $argv[1] ?? '';
$fail = 0; $total = 0;

foreach ($pure as $short) {
    $file = "$root/src/$short.php";
    if (!is_file($file)) { continue; }
    require_once $file;
    $class = "GlpiPlugin\\Sac\\$short";
    if (!method_exists($class, 'selfChecks')) { continue; }
    foreach ($class::selfChecks() as $name => $check) {
        if ($filter !== '' && !str_contains($name, $filter)) { continue; }
        $total++;
        try { $check(); echo "PASS  $name\n"; }
        catch (\Throwable $e) { $fail++; echo "FAIL  $name — {$e->getMessage()}\n"; }
    }
}
echo "\n$total checks, $fail failed\n";
exit($fail === 0 ? 0 : 1);
```

```php
    public static function forEolDays(
        int $daysUntilEol,
        int $horizon = 365,
        int $highDays = 90,
        int $mediumDays = 180
    ): ?string {
        if ($daysUntilEol < 0) {
            return 'Critical';
        }
        if ($daysUntilEol <= $highDays) {
            return 'High';
        }
        if ($daysUntilEol <= $mediumDays) {
            return 'Medium';
        }
        if ($daysUntilEol <= $horizon) {
            return 'Low';
        }
        return null;

        if ($expired) {
            return 'High';

        $ratio = $installs / $seats;
        if ($ratio > 1.5) {
            return 'High';
        }
        if ($ratio > 1.1) {
            return 'Medium';
        }
        return 'Low';
    }
```

```php
    /** Map: endoflife product slug => callable(string $osName): ?string */
    private const CYCLE_RULES = [
        'windows-server' => [self::class, 'cycleWindowsServer'],
        'windows'        => [self::class, 'cycleWindowsClient'],
    ];

    public static function cycleFromVersion(string $product, string $osName): ?string
    {
        $product = strtolower(trim($product));
        $name    = strtolower($osName);

        if (isset(self::CYCLE_RULES[$product])) {
            return (self::CYCLE_RULES[$product])($name);
        }

        // Ubuntu: YY.MM (keep two dotted groups)
        if ($product === 'ubuntu' && preg_match('/(\d{2}\.\d{2})/', $name, $m)) {
            return $m[1];
        }

        // Generic: first integer run = major version (rhel, debian, centos, sles, …)
        if (preg_match('/(?:release\s+)?(\d+)(?:\.\d+)*/', $name, $m)) {
            return $m[1];
        }

        return null;
    }

    private static function cycleWindowsServer(string $name): ?string
    {
        if (!preg_match('/server\s+(\d{4})(\s*r2)?/', $name, $m)) {
            return null;
        }
        return $m[1] . (isset($m[2]) && trim($m[2]) !== '' ? '-R2' : '');
    }

    private static function cycleWindowsClient(string $name): ?string
    {
        if (preg_match('/windows\s+(\d{1,2})/', $name, $m)) {
            return $m[1];
        }
        return null;
    }

    public static function fuzzyProduct(string $osName, array $productSlugs): ?string
    {
        $name = strtolower($osName);

        // Explicit aliases first — GLPI OS names rarely contain the raw slug.
        $aliases = [
            'red hat enterprise linux' => 'rhel',
            'rhel'                     => 'rhel',
            'ubuntu'                   => 'ubuntu',
            'debian'                   => 'debian',
            'centos'                   => 'centos',
            'suse'                     => 'sles',
            'windows server'           => 'windows-server',
            'esxi'                     => 'vmware-esxi',
            'vmware esxi'              => 'vmware-esxi',
        ];
        foreach ($aliases as $needle => $slug) {
            if (str_contains($name, $needle) && in_array($slug, $productSlugs, true)) {
                return $slug;
            }
        }

        // Fallback: a slug whose words all appear in the name, exactly one match.
        $hits = [];
        foreach ($productSlugs as $slug) {
            $words = explode('-', $slug);
            $all = true;
            foreach ($words as $w) {
                if ($w !== '' && !str_contains($name, $w)) { $all = false; break; }
            }
            if ($all) { $hits[] = $slug; }
        }
        return count($hits) === 1 ? $hits[0] : null;
    }
```

```php
<?php

namespace GlpiPlugin\Sac;

final class Http
{
    /** @var callable(string,int):?string|null */
    public static $transport = null;

    public static function get(string $url, int $timeout = 15): ?string
    {
        if (self::$transport !== null) {
            return (self::$transport)($url, $timeout);
        }
        if (class_exists('\\Toolbox') && method_exists('\\Toolbox', 'getURLContent')) {
            $body = \Toolbox::getURLContent($url);
            return $body !== false && $body !== '' ? $body : null;
        }
        $ctx  = stream_context_create(['http' => ['timeout' => $timeout, 'ignore_errors' => true]]);
        $body = @file_get_contents($url, false, $ctx);
        return $body !== false && $body !== '' ? $body : null;
    }

    public static function selfChecks(): array
    {
        return [
            'http/transport-override' => static function (): void {
                self::$transport = static fn(string $u, int $t): ?string => "body:$u";
                sac_assert_eq(self::get('https://x/y'), 'body:https://x/y', 'stub used');
                self::$transport = null;
            },
        ];
```

```php
}

    public static function upsert(array $input, array $computerIds, string $rawAssetText, RunLog $run): ?int
    {
        if (!self::isAvailable()) {
            $run->bump('errors');
            return null;
        }
        if ($rawAssetText !== '') {
            $input['raw_asset_text'] = mb_substr($rawAssetText, 0, 255); // NB: VM has mbstring
        }
        $f   = new \GlpiPlugin\Riskregister\Finding();
        $hit = $f->find(['entities_id' => $input['entities_id'], 'code' => $input['code']]);
        if ($hit) {
            $id = (int) array_key_first($hit);
            $f->update(['id' => $id] + self::mergeableOnUpdate($input));
        } else {
            $new = $f->add($input);
            if ($new === false) {
                $run->bump('errors');
                \Toolbox::logInFile('sac', 'Finding->add failed: ' . json_encode($input) . "\n");
                return null;
            }
            $id = (int) $new;
        }
        $run->bump('findings_upserted');

        foreach ($computerIds as $cid) {
            $li  = new \GlpiPlugin\Riskregister\Finding_Item();
            $has = $li->find([
                'plugin_riskregister_findings_id' => $id,
                'itemtype' => 'Computer',
                'items_id' => $cid,
            ]);
            if (!$has) {
                $li->add([
                    'plugin_riskregister_findings_id' => $id,
                    'itemtype' => 'Computer',
                    'items_id' => (int) $cid,
                ]);
            }
        }
        return $id;
    }

        if (!class_exists(\GlpiPlugin\Riskregister\Import\ImportSupport::class)) {

    }

    public static function appendClearedNote(string $code, int $entitiesId, string $why, RunLog $run): void
    {
        if (!self::isAvailable()) { return; }
        $f   = new \GlpiPlugin\Riskregister\Finding();
        $hit = $f->find(['entities_id' => $entitiesId, 'code' => $code]);
```
